# Machine Learning-Based Prediction of Novel Oxide Compounds

## Project Overview

This project explores the application of **Machine Learning (ML) and Data Science to materials discovery**, focusing on predicting and identifying potentially promising oxide compounds from chemical data.

Using a curated dataset of **2,000 compounds selected from a larger collection of approximately 580,000 molecules**, the project investigates how data-driven techniques can help uncover patterns in chemical properties and support the discovery of novel materials.

The aim is to develop an end-to-end machine learning workflow, from data preprocessing and exploratory analysis to model development, evaluation, and interpretation.

## Objectives

- **Explore Chemical Data:** Analyse chemical datasets to understand distributions, relationships, and patterns within oxide compounds.
- **Data Preprocessing:** Apply data cleaning, transformation, and feature preparation techniques to make datasets suitable for machine learning.
- **Predictive Modelling:** Develop and experiment with machine learning algorithms to investigate their ability to predict promising oxide compounds.
- **Model Evaluation:** Assess model performance using appropriate evaluation metrics and compare different modelling approaches.
- **Materials Discovery:** Explore how machine learning can support data-driven research and accelerate the identification of potentially useful materials.
